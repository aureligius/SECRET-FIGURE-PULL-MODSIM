# SECRET-FIGURE-PULL-MODSIM

This program is a stochastic simulation program built to evaluate the probability distributions, financial risks, and market dynamics of hunting "Secret" figures in 3 blind-box toys. This project maps the mechanics of Pop Mart’s collectors' ecosystem using a **Discrete-Time Non-Homogeneous Markov Chain** combined with **Bayesian Price Volatility Modeling**.

Developed as a final project for **Stochastic Modeling & Simulation (TIF212247)**, Department of Electrical Engineering and Information Technology (DTETI), Universitas Gadjah Mada.
